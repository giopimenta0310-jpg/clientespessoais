# gio. — base de contexto da marca pessoal

Esta pasta concentra o contexto estratégico construído para a marca pessoal de Giovanna Pimenta, a `gio.`. Ela existe para que o trabalho possa continuar em qualquer dispositivo sem depender do histórico de um chat específico.

3. Consulte [`02-diagnostico-instagram.md`](02-diagnostico-instagram.md) para ver a leitura do perfil atual.
4. Use [`03-estrategia-de-perfil-e-conteudo.md`](03-estrategia-de-perfil-e-conteudo.md) como guia de implementação.

## Princípio central

> Profissionalizar os sinais do perfil, não esterilizar a pessoa.

O objetivo não é transformar Giovanna em uma personagem corporativa. É fazer com que personalidade, repertório e vida real convivam com provas claras de competência, processo e trabalho.
