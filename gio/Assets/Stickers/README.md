# Biblioteca de stickers — gio.

Elementos vetoriais reutilizáveis para Stories, carrosséis, capas, destaques e peças da marca pessoal `gio.`.

## Direção visual

- linguagem plana, editorial e levemente orgânica;
- formas simples, expressivas e fáceis de combinar;
- contorno creme que funciona como recorte de sticker;
- ausência de sombras, volume artificial e efeitos brilhantes;
- tipografia de apoio: Instrument Sans, com fallback para Arial;
- fundo transparente em todos os arquivos individuais.
