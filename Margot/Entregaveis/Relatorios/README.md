## Transferência para outro computador

As prévias, folhas de contato e quadros de vídeos são versões de consulta. Os originais permanecem no [Drive de captação](https://drive.google.com/drive/folders/1ldW88dHdEDBjWQTYhDzUp_K5Twk5UG-U); não estão no Git. Arquivos que não aparecem nessa pasta podem estar no acervo 17-10 ou em outro local indicado pela Giovanna.

O calendário guarda alterações no navegador. Exporte JSON antes de trocar de máquina e importe no outro navegador. O Git sincroniza os arquivos versionados, mas não o armazenamento local do navegador, a plataforma de aprovação ou o Instagram.

Para regenerar a base: `python3 Planejamento/gerar_planejamento.py`. Exporte novamente o HTML de impressão para atualizar o PDF. Preservar edições exportadas antes de gerar.
