## Guardar ideias

Abas: diagnóstico, calendário e banco. Setas abrem outros meses. Clique em um dia ou use o banco para adicionar uma ideia; data é opcional. Alterações ficam neste navegador. Exporte JSON para guardar uma cópia ou transferir a outro computador; importar substitui os dados locais após confirmação. Não há sincronização automática com GitHub, plataforma ou Instagram. Atualizações da base preservam edições locais que diferem da versão anterior.

O PDF retrata a base desta versão. Editar o HTML não atualiza o PDF nem os arquivos-fonte automaticamente. Preserve exportações feitas no navegador antes de regenerar com `python3 gerar_planejamento.py`.
